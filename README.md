# Apuração presidencial 2026

Site estático no GitHub Pages. O mapa lê `dados.json`. O desenho dos estados fica em `mapa.json` e não muda.

A apuração é buscada nos arquivos públicos do TSE a cada 20 minutos, até 28/10/2026. Se os números forem os mesmos, nada é republicado. Para buscar na hora: em GitHub, aba Actions, fluxo "Atualizar apuração", botão Run workflow.

O texto e o visual ficam em `index.html`. Depois de editar, envie a alteração para o branch `main`. O site em https://rafaeldamasio.github.io/apuracao-2026/ acompanha o branch.
